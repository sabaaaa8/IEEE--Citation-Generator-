 IEEE Citation Generator

 About Project

IEEE Citation Generator is a web-based application developed to generate citations in IEEE format quickly and accurately. This project helps students, researchers, and academic users create properly formatted citations for different reference types.

 Features

* Generate IEEE citations easily
* Multiple citation types supported:

  * Website
  * Report
  * Conference
  * Book
  * Journal
  * Magazine
  * Thesis
  * Dataset
  * Patent
* Copy generated citations
* Download citations as PDF
* User-friendly interface
* Responsive design for mobile and desktop

 Technologies Used

* HTML
* CSS
* JavaScript
* jsPDF Library

 Purpose

The purpose of this project is to simplify citation generation in IEEE format and reduce manual formatting errors in academic references.

 How to Use

1. Select a citation type.
2. Fill in the required details.
3. Click on **Generate**.
4. Copy the citation or download it as a PDF.
